# KONTROVERSI IJAZAH GIBRAN: INVESTIGASI FORENSIK DOKUMEN DAN SISTEM PENDIDIKAN

Dokumenter investigasi forensik independen berdurasi 17 menit 54 detik (1080p 30fps) mengenai riwayat pendidikan dan keabsahan ijazah Gibran Rakabuming Raka. Menelusuri kronologi mobilitas akademik lintas benua dari Solo, Singapura, Sydney, hingga gelar sarjana University of Bradford di Inggris; membedah sistem kualifikasi internasional (skema *pathway* dan *transnational education*); mengaudit dokumen Surat Keputusan Penyetaraan Kemendikbudristek dan verifikasi Komisi Pemilihan Umum; mengurai perang narasi dan gugatan hukum di ruang publik; serta merefleksikan standar hukum dan etika transparansi kepemimpinan nasional.

   - Kesenjangan pemahaman antara sistem linier Indonesia dan sistem modular negara Persemakmuran.

   - Skema *Transnational Education* (TNE): kemitraan akademik MDIS Singapura dengan University of Bradford UK.
   - Mengapa ijazah diterbitkan resmi oleh University of Bradford (*Bachelor of Science in Marketing, Second Class Honours Second Division*).

3. **Babak III — Audit Dokumen dan Penyetaraan Resmi: Di Balik Surat Keputusan Kementerian (Shot 037–054)**

   - Konferensi pers di Balai Kota Surakarta: pembuktian fisik segel timbul, nomor registrasi, transkrip modular, dan hologram legalisir.

4. **Babak IV — Anatomi Narasi di Ruang Publik: Viralitas, Perang Dokumen, dan Gugatan Hukum (Shot 055–072)**

   - Paradoks antara syarat minimal legalitas formal dengan tuntutan legitimasi moral masyarakat.

   - Epilog: memisahkan fakta forensik administratif dari distorsi partisan demi kematangan demokrasi.

## 3. Standar Naskah Anti-Slop (Anti-Slop Writing Standard)

Naskah narasi (`input/script.md`) disusun berdasarkan standar kepenulisan investigasi jurnalistik dingin:
- **0 Digit Angka:** Seluruh angka, tahun, nomor pasal, dan nomor surat keputusan dieja penuh dengan huruf alfabet (contoh: *dua ribu enam*, *seribu tiga ratus tahun dua ribu sembilan belas*, *strata satu*). Menghilangkan risiko pelafalan salah oleh engine TTS.
- **0 Tanda Em-Dash / En-Dash:** Tanda hubung panjang dieliminasi dan digantikan oleh tanda baca koma atau titik agar ritme jeda nafas narator terdengar natural.
- **Tone Objektif & Netral:** Menghindari bahasa sensasionalis, klise AI, atau praduga partisan; fokus sepenuhnya pada audit forensik warkah dokumen dan kerangka regulasi pendidikan internasional.

## 4. Arsitektur Visual Sinematik: 35mm Warm Tungsten

Seluruh 90 adegan menggunakan prompt visual terkunci (*Style Lock*) dengan parameter:
- **Optik & Framing:** Widescreen 16:9 Full-Bleed tanpa border, tanpa frame ganda, dan tanpa kolase buatan. Kamera simulasi 35mm anamorphic dengan kedalaman ruang dangkal (*shallow depth of field*).
- **Pencahayaan (Lighting):** *Warm tungsten banker's lamps*, lampu sorot arsip perunggu, berkas cahaya diagonal dengan partikel debu melayang (*volumetric dust motes*), kontras tinggi jatuh ke bayangan obsidian (*chiaroscuro tenebrism*).
- **Palet Warna:** Amber hangat (#FF9E3B), gading kertas kuno (*aged ivory parchment*), kayu mahogani gelap, aksen kuningan (*antique brass*), dan hitam pekat tinta stempel.

## 5. Mesin Render & Perakitan Audio-Visual

Pipeline render `render_continuous_babak.py` menerapkan standar bioskop digital:

```
[90 Gambar Flow 4K] ──> [Ken Burns Push-in] ──> [Crossfade 0.75s] ──┐
                                                                    ├──> [Compositing MP4]
[Audio Supertonic M2] ──> [Whisper Alignment] ──> [Subtitle SRT] ──┤         │
                                                                    │         ▼
[Grunge Texture 35mm] ──> [Screen Blend + Vignette] ────────────────┘  [Master Film Final]
                                                                              ▲
[Backsong Sinematik] ──> [Sidechain Compressor Ducking (Auto-Volume)] ────────┘
```

1. **Continuous Speech Synthesis:** Narasi disintesis per babak untuk memastikan intonasi vokal mengalir tanpa *robotic micro-silence*.
2. **Acoustic Word Alignment:** Setiap kata dipetakan menggunakan `faster-whisper` (model tiny/base) langsung ke getaran vokal asli.
3. **Anti-Lonely Phrasing:** Setiap baris subtitle dijamin memiliki 3–7 kata. Tidak ada baris subtitle sebatang kara (1–2 kata).
4. **Watermark Safe Placement:** Watermark "BANYAK TAU" diposisikan di ketinggian `y=540`, memberikan ruang lebih dari 200px dari subtitle bagian bawah (`MarginV=48`).
5. **Bridges & Outro:** Tiap pergantian babak dilengkapi *chapter card* dengan efek distorsi *burn/glitch* dan ditutup kartu epilog mesin tik selama 33 detik.

## 8. Panduan Menjalankan Sistem

### Persyaratan Sistem
- Python 3.10+ & Node.js 20+
- `ffmpeg` & `ffprobe` (terpasang di PATH sistem)
- Package manager `uv` (rekomendasi untuk eksekusi cepat)

### Menjalankan Studio Dashboard
Untuk memantau adegan, naskah, dan memutar klip hasil produksi:
```bash
python src/dashboard.py
```
Akses di browser melalui: `http://127.0.0.1:5188/`

### Menjalankan Perakitan Master Film Mandiri
Untuk merender ulang film secara utuh dari aset yang tersedia:
```bash
uv run --with faster-whisper --with "av<14" --with soundfile --with Pillow --with opencv-python \
  python src/render_continuous_babak.py .
```

Master film akan otomatis dihasilkan di folder `export/`.
